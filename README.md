# Integrator TomarLublin – wydania aplikacji na Androida

Publiczne repozytorium z gotowymi wersjami aplikacji **Integrator TomarLublin** (Android 8.0+). Kodu źródłowego tu nie
ma (jest w prywatnym repozytorium `Integrator-TomarLublin-Zrodlo`, folder `android/`). Pliki są w zakładce
**[Releases](../../releases)**.

- Tagi: `android-vX.Y.Z`, plik `Integrator-TomarLublin-X.apk` podpisany zawsze tym samym kluczem.
- Publikuje automat **Android: budowanie i wydanie** z repozytorium kodu.
- Aplikacja sprawdza wydania tego repozytorium przy uruchomieniu i przyciskiem w Ustawieniach.

## Instalacja na telefonie

1. Na telefonie otwórz [najnowsze wydanie](../../releases/latest) i pobierz plik `.apk` (logowanie niepotrzebne).
2. Otwórz pobrany plik. Android zapyta o zgodę na instalowanie aplikacji z przeglądarki, zezwól.
3. Kolejne wersje aplikacja zaproponuje sama. Instaluj je na poprzednią wersję, bez odinstalowywania: ustawienia i
   hasła zostaną.

## Historia

Do 15.11.2026 repozytorium nazywało się `integrator-android-wydania`. GitHub przekierowuje starą nazwę, więc telefony ze
starszą wersją aplikacji dalej znajdują aktualizacje. Wydania programu na Windows są w
`Integrator-TomarLublin-Wydania-Windows`.
